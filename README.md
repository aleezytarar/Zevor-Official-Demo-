# ZEVOR – Define Your Legacy

A professional luxury fragrance brand website designed with an elegant black and gold theme.

## About the Project
ZEVOR is a luxury fragrance brand website demo created to showcase premium design, fragrance presentation, and a modern shopping experience.

## Features
- Premium black and gold design
- Responsive mobile-friendly layout
- Automatic hero image slider
- Luxury loading animation
- Interactive navigation bar
- Product showcase – LEGACY
- WhatsApp order button
- Newsletter subscription demo
- Back to top button
- Social media links

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome

## Project Files
- `index.html` – Website structure
- `style.css` – Website styling
- `script.js` – Website functionality
